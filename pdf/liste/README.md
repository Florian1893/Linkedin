# PDF: Was ohne dich rausgehen darf

Zweites Profil-PDF, gebaut am 17.09.2026 auf Florians Wunsch ("so ein PDF zum Downloaden, einfach anderes Thema").

Unterschied zum ersten PDF (`pdf/mehrwert/fuenf-dinge-selbst-automatisieren.pdf`): das erste zeigt fuenf Ablaeufe,
die ein Inhaber selber automatisieren kann. Dieses hier loest ein anderes Problem, naemlich die fehlende Grenze.
Es sagt nicht, was automatisiert wird, sondern was ohne den Chef entschieden werden darf.

Sechs Bereiche, je mit drei Feldern (was heute passiert, wo die Grenze hingehoert, was trotzdem zum Chef muss)
und einem fertigen Satz zum Aufschreiben. Seite 5 ist eine Vorlage zum Ausfuellen, Seite 6 das Angebot.

Bereich 03 (Regie und Nachtraege) bleibt bewusst ganz beim Chef. Das ist der Glaubwuerdigkeitsanker:
ein Dokument, das alles wegdelegieren will, nimmt ihm niemand ab. Der Befund stammt aus dem
Zielgruppen-Test vom 17.09.: alles was den Preis bewegt oder Regie ausloest, MUSS zum Inhaber,
wegen Haftung und Gewaehrleistung.

Design uebernommen aus pdf/mehrwert (gleiche Farben, gleiche Schrift, gleiche Seitenarchitektur),
damit beide PDFs im Profil als Reihe erkennbar sind.

Rendern: node pdf/liste/render-liste.js
Der Renderer meldet Seitenzahl und jeden Ueberlauf in Pixeln. Bei "Ueberlauf: keiner" passt alles auf A4.

# LinkedIn BetriebsFlow

Arbeitsarchiv fuer Florians LinkedIn-Content.

## Arbeitsteilung

Der Skill `betriebsflow-linkedin` ist das Regelwerk: Zielgruppe, Schreibregeln, Ehrlichkeits-Leitplanken, Gewinner-Vorlagen. Dieses Repo ist das Gedaechtnis: was gepostet wurde, wie es lief, was daraus folgt. Regeln werden hier nicht dupliziert, sonst driftet es auseinander.

## Struktur

- `wissen/algorithmus-2026.md` Aktueller Stand des LinkedIn-Algorithmus mit Quellen
- `wissen/lernprotokoll.md` Alle Posts mit Impressions, sortiert, plus abgeleitete Regeln
- `wissen/themenspeicher.md` Bespielte und offene Themen, Content-Saeulen
- `posts/` Ein File pro Post

## Ablauf pro Post

1. Lernprotokoll und Themenspeicher lesen
2. Vorlage waehlen (A bis D aus dem Skill)
3. Post schreiben
4. Regel-Check: keine Gedankenstriche, kein scharfes s, echte Umlaute, keine Hashtags, genau eine Frage am Schluss, 900 bis 1300 Zeichen, Fliesstext
5. Als `posts/JJJJ-MM-TT-thema.md` ablegen
6. Nach zwei Tagen Impressions nachtragen und ins Lernprotokoll einordnen

## Beim Posten

Dienstag oder Donnerstag. Die ersten 30 Minuten erreichbar bleiben und jeden Kommentar sofort beantworten, mit einem echten Satz. Dazu auf drei bis fuenf fremden Handwerker-Posts kommentieren. In kleinem Netzwerk entscheidet das ueber die Reichweite.

Keine URL im Post und keinen Link im ersten Kommentar. Beides kostet Reichweite.
